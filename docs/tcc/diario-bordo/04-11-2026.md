1. **Clonar o repositório** (público, não precisa de pendrive):

```bash
git clone https://github.com/Solution-Explores/SigmaTI.git
```

2. **Entrar na branch dos diários da semana**, onde estão este diário e o PR semanal [#76](https://github.com/Solution-Explores/SigmaTI/pull/76) (rascunho):

```bash
cd SigmaTI && git switch docs/semana-02-11-continuacao
```

3. **Escrever o diário da tarde e da noite** neste mesmo arquivo (`docs/tcc/diario-bordo/04-11-2026.md`) e empurrar, sem branch nova:

```bash
git add docs/tcc/diario-bordo && git commit -m "docs(diario): 04/11, tarde" && git push
```

4. **Para o código** (passos 3 a 6 do roteiro), voltar para a `develop` e criar a branch de cada atividade a partir dela:

```bash
git switch develop && git pull --ff-only origin develop
```

5. **Ambiente Python**, uma vez, na pasta do projeto:

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pip install -e "./engenharia[api,dev]"
```

6. **Primeiro passo do dia:** clicar no merge do #69 e do #70 e conferir a `develop` (passo 1 do roteiro). Docker Desktop precisa estar ligado, em contêineres Linux.

No fim da semana, o #76 sai do rascunho e é integrado com todos os diários.
