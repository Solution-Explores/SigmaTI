> Como usar: copie este arquivo para `AAAA-MM-DD.md` (por exemplo, `2026-11-05.md`), nesta mesma pasta, e preencha no fim do dia. Apague estas linhas de instrução.
> Uma vez por semana, abra um PR só com os diários (nome: `docs: diário de bordo da Joyce (semana de DD/MM)`) e marque o Vinícius como revisor.
